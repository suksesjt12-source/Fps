# TACTICAL STRIKE: ZERO HOUR — Godot Engine 4.3 Android FPS

Game First Person Shooter 3D fiksi ilmiah taktis untuk Android, dibangun menggunakan **Godot Engine 4.3** (Compatibility Renderer / OpenGL ES 3) dengan arsitektur **ARM64**.

## Cara Build APK Langsung dari HP Android (GitHub Actions)

1. Ekstrak hasil unduhan proyek atau push repository ini ke GitHub.
2. Buka repository di browser HP Android -> tab **Actions**.
3. Workflow **Build Android APK (Godot 4.3)** akan berjalan otomatis saat push ke `main` (atau klik **Run workflow**).
4. Setelah selesai, buka run terbaru dan unduh artifact **`tactical-strike-zero-hour-android-apk`**.
5. Ekstrak ZIP dan instal `tactical_strike_zero_hour.apk` di perangkat Android ARM64.
